Welcome to My Node.js Web Server

This project demonstrates how routing works using the built-in HTTP module in Node.js. Different URLs return different HTML pages through a simple server.

Learn More View Services

Project Highlights

Routing

The server checks the requested URL and returns the correct page.

Asynchronous File Handling

HTML files are read using fs.readFile() so the server remains responsive.

Custom Error Page

If the requested route is not available, a custom 404 page is displayed.
